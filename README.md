## About Me

I'm a software engineer with a background in AI & Machine Learning, interested in building useful products and understanding how technology works beyond the code.

My journey started with a diploma in electronics, where I worked with hardware, sensors, and circuits. I later moved into software development, building web applications, mobile apps, backend systems, and SaaS products.

Today, I'm pursuing an **MSc in Data Science at the University of Europe for Applied Sciences, Potsdam, Germany**, while continuing to explore software engineering, AI, data, and product development.

- Building web applications, SaaS products, and software systems.
- Exploring Data Science, Machine Learning, and Generative AI.
- Interested in backend engineering, databases, cloud infrastructure, and scalable architecture.
- Learning German and exploring the technology ecosystem in Germany.
- Always interested in meaningful projects and engineering collaborations.
